# praktyka_project / task-manager

Projekt praktyk WTZ — struktura katalogów zgodna z zadaniem `directory status`.

```
task-manager/
├── frontend/            # HTML, CSS, JS
├── backend/             # PHP lub ASP.NET Core Web API
├── database/            # skrypty SQL, kopie zapasowe
├── docs/                # wymagania, ERD, makiety
├── tests/               # przypadki testowe, testy automatyczne
├── .github/workflows/   # CI
├── .gitignore
└── README.md
```

> Uwaga: w tym repozytorium katalog główny `praktyka_project/` odpowiada katalogowi `task-manager/` ze скриншота.

## Frontend
Prosty start: `frontend/index.html` + `style.css` + `app.js`.

## Backend
Miejsce na PHP lub ASP.NET Core Web API.

## Database
Skrypty SQL w `database/`.

## Docs
Wymagania, ERD, makiety w `docs/`.

## Tests
Przypadki testowe i testy automatyczne w `tests/`.

## CI
Przykładowy workflow: `.github/workflows/ci.yml`.
