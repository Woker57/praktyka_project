# Wymagania (docs/wymagania.md)

## Cel
Prosty Task Manager: frontend HTML/CSS/JS + backend PHP lub ASP.NET Core Web API + baza SQL.

## Funkcje
1. Dodawanie / usuwanie / oznaczanie zadań jako wykonane.
2. Przechowywanie w bazie danych.
3. Testy + CI.

## ERD
- tasks(id PK, title, done, created_at)

## Makiety
- Lista zadań + input + przycisk Dodaj (patrz frontend/index.html).
